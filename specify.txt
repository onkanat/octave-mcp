# Octave MCP Server - Copilot Kılavuzu

**Versiyon**: 0.2.0 | **Teknoloji Stack**: Python 3.11+, FastMCP + FastAPI, GNU Octave, MCP

## Proje Mimarisi

**Çekirdek Modüller** (src/ altında):
- `mcp_server.py`: FastMCP ile MCP STDIO araçları (octave_run, publish_octave, grabcode_octave, clean_octave)
- `api/endpoints.py`: FastAPI ile HTTP API (/run, /publish, /grabcode, /cleanup)
- `services/`: octave_runner, publish_service, grabcode_service, cleanup_service
- `models/`: Run, Publish, Grabcode, ImageResult veri modelleri
- `utils/`: resource_limits, config, error_format, logging

**Temel Özellikler**:
- Kod çalıştırma: session tabanlı, resource limit, timeout
- Publish: HTML çıktı + base64, truncation uyarısı
- Grabcode: HTML'den kaynak geri çıkarma
- Cleanup: otomatik eski session temizliği

## Kod Üretim Kuralları

**GNU Octave Uyumluluğu**:
- MATLAB özel API kullanma; sadece GNU Octave sözdizimi
- Vektörizasyon zorunlu; gereksiz döngü yasak
- Element işlemler: `.*`, `./`, `.^` (nokta notasyonu)
- Grafik kaydetme: `print('-dpng','figure.png','-r150')`
- Deterministik rastgelelik: `rand("seed",0)`
- `input()` fonksiyonu yasak

**Vektörizasyon Örneği**:
```octave
% KÖTÜ:
for i=1:length(x); y(i) = sin(x(i)^2); endfor

% İYİ:
y = sin(x.^2);
```

**Resource Limit Kuralları**:
- CPU: 10s default, bellek: 512MB default
- Çıktı truncation: 20k karakter, resim: 5MB
- Timeout: 30s subprocess

## Hata Raporlama Formatı

Standart blok yapısı:
```
---MCP_ERROR_START---
identifier: OCTAVE_SYNTAX_ERROR
message: Sözdizimi hatası tespit edildi
stack: script.m:5 (main function)
ipucu: Satır sonuna ';' ekleyin
---MCP_ERROR_END---
```
